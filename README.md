> [!IMPORTANT]
> **Проект архивирован и больше не поддерживается.**
>
> У меня больше нет желания и времени продолжать его разработку.
>
> Изначально VK Desktop был построен как Electron-обёртка над веб-версией VK. В ретроспективе это было не лучшим архитектурным решением. Стоило изначально делать собственный интерфейс и использовать VK API там, где это возможно.
>
> При этом публичный VK API не предоставляет полного набора возможностей официального клиента, поэтому полностью повторить функциональность VK с собственным интерфейсом без использования внутренних API всё равно было бы сложно.
>
> Репозиторий сохранён в архивном виде.

## Что было реализовано

* VK в отдельном desktop-окне с интеграцией в Windows.
* Интеграция VK Next.
* Discord Rich Presence для музыки.
* Управление музыкой и быстрые переходы через системный трей.
* Счётчик непрочитанных сообщений и уведомления.
* Сворачивание приложения в трей.
* Профили производительности и управление фоновым потреблением памяти.
* Автоматическая проверка обновлений.
* Windows x64 installer.
* Кастомный title bar и дополнительные desktop-функции поверх веб-интерфейса VK.

## Архитектура

VK Desktop использует Electron и загружает веб-версию VK внутри `BrowserWindow`.

Поверх неё клиент добавляет собственную desktop-интеграцию, стили, системный трей, Discord RPC, VK Next, обработку ссылок, обновления и другие функции.

Это не самостоятельная реализация интерфейса VK и не полноценный нативный клиент.

## Сборка из исходников

Требования:

* Windows x64
* Node.js 24
* npm 11

```powershell
git clone https://github.com/yamixdev/vk-desktop.git
cd vk-desktop
npm ci
npm start
```

Сборка installer:

```powershell
npm run build
```

Основные команды:

| Команда             | Назначение                       |
| ------------------- | -------------------------------- |
| `npm start`         | Запуск приложения                |
| `npm run check`     | Линтер, тесты и проверка VK Next |
| `npm run build:dir` | Unpacked Windows x64 сборка      |
| `npm run build`     | Создание NSIS installer          |

## Безопасность

В проекте использовались стандартные механизмы изоляции Electron:

* `nodeIntegration: false`
* `contextIsolation: true`
* `sandbox: true`
* ограниченный IPC
* фильтрация навигации и внешних URL
* ASAR integrity
* отключение небезопасных Electron fuses

Архивирование проекта означает, что будущие изменения Electron, Chromium, VK или VK Next больше не отслеживаются. Используйте старые сборки с учётом этого.
