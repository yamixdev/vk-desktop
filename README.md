## Возможности

- полноценный интерфейс VK в отдельном desktop-приложении;
- встроенный и проверяемый по SHA-256 артефакт VK Next;
- настройки VK Next в отдельном окне `1280×720`;
- Discord Rich Presence для музыки без обновления статуса каждую секунду;
- управление воспроизведением и быстрые переходы из системного трея;
- SPA-переходы к музыке, сообщениям и главной странице без лишней перезагрузки;
- уведомления, счётчик непрочитанных сообщений и сворачивание в трей;
- встроенная проверка обновлений и Windows x64 installer;
- sandbox, context isolation, проверка IPC и строгая политика внешних ссылок.

## Установка

1. Открой [последний релиз](https://github.com/yamixdev/vk-desktop/releases/latest).
2. Скачай `VK-Desktop-Setup-<version>.exe`.
3. Запусти установщик и выбери папку установки.

> [!WARNING]
> Текущие сборки могут не иметь платной Authenticode-подписи. Windows SmartScreen
> в таком случае способен показать предупреждение «Неизвестный издатель».
> Загружай приложение только из официального репозитория `yamixdev/vk-desktop`.

## VK Next

VK Next включён по умолчанию. Его можно отключить через
`Файл → Настройки → VK Next`; переключение требует перезагрузки страницы VK.
Перед загрузкой приложение сверяет версию, список файлов и SHA-256 расширения с
закреплёнными метаданными. Настройки открываются через
`Файл → Настройки → Открыть настройки VK Next`.

VK Next является сторонним компонентом. Права на него принадлежат его
правообладателям; proprietary-лицензия VK Desktop не присваивает эти права.

## Память и фоновой режим

Chromium самостоятельно управляет большей частью памяти. Дополнительно VK
Desktop может запрашивать сборку мусора только у разросшегося renderer-процесса
и только когда окно скрыто не менее пяти минут. Проверка выполняется раз в
минуту, между очистками выдерживается минимум 15 минут. Очистка пропускается,
если играет музыка, страница загружается или подключены DevTools.

Страница намеренно не выгружается целиком: иначе перестали бы работать музыка и
уведомления в фоне. На контрольном чистом профиле idle-потребление составляло
около 407 МБ private working set; фактическое значение зависит от страницы,
расширения, GPU и продолжительности сессии.

## Сборка из исходников

Понадобятся Windows x64, Node.js 24 и npm 11.

```powershell
git clone https://github.com/yamixdev/vk-desktop.git
cd vk-desktop
npm ci
npm start
```

Создание installer:

```powershell
npm run build
```

Полезные команды:

| Команда | Назначение |
| --- | --- |
| `npm run check` | Линтер, быстрые unit-тесты и проверка VK Next |
| `npm run build:dir` | Unpacked Windows x64 сборка |
| `npm run build` | NSIS installer без публикации |
| `npm run publish` | Сборка и публикация релиза; подпись необязательна |

## Безопасность

- удалённый контент работает без Node.js integration;
- renderer запускается в sandbox с context isolation;
- IPC принимает только ограниченные схемами сообщения от главного frame VK;
- внешние URL открываются системным браузером, а VK redirector не загружается в
  клиент;
- локальные служебные страницы доступны только через закрытый allowlist
  `vk-desktop://local`;
- production-сборка проверяет ASAR integrity и отключает опасные Electron fuses.
