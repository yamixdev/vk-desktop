Неофициальный клиент VK для Windows. Проект объединяет веб-интерфейс VK,
интеграцию VK Next и функции настольного приложения в одном окне.

## Возможности

- Интерфейс VK в отдельном окне с интеграцией в Windows.
- Опциональный VK Next с проверкой версии, состава файлов и контрольной суммы.
- Discord Rich Presence с информацией о текущем треке.
- Управление музыкой и переходы к сообщениям, музыке и главной странице из
  системного трея без полной перезагрузки VK.
- Счётчик непрочитанных сообщений, уведомления и сворачивание в трей.
- Профили производительности и осторожная очистка памяти в фоновом режиме.
- Встроенная проверка обновлений и установщик для Windows x64.

## Установка

1. Перейти на страницу [последнего релиза](https://github.com/yamixdev/vk-desktop/releases/latest).
2. Скачать `VK-Desktop-Setup-<version>.exe`.
3. Запустить установщик и выбрать каталог установки.

> [!WARNING]
> Проект пока не использует коммерческий сертификат Authenticode, поэтому
> Windows SmartScreen может показать предупреждение «Неизвестный издатель».
> Рекомендуется загружать приложение только из официального репозитория
> `yamixdev/vk-desktop`.

## VK Next

VK Next включён по умолчанию и доступен через меню `☰` в заголовке окна.
Включение или отключение расширения требует перезагрузки страницы VK. Перед
загрузкой клиент сверяет версию, список файлов и SHA-256 с закреплёнными
метаданными. В том же меню находится отдельный пункт настроек VK Next.

VK Next является сторонним компонентом. Права на него принадлежат его
правообладателям; proprietary-лицензия VK Desktop не присваивает эти права.

## Память и фоновой режим

Основное управление памятью выполняют Chromium и V8. Дополнительная очистка
запрашивается только для разросшегося renderer-процесса, когда окно достаточно
долго находится в фоне. Клиент не запускает её во время воспроизведения музыки,
загрузки страницы или работы DevTools и выдерживает длительную паузу между
повторными запросами.

Страница VK намеренно не выгружается целиком, поскольку это остановило бы
фоновую музыку и уведомления. Потребление памяти не является фиксированным и
зависит от открытого раздела, VK Next, GPU-процесса и продолжительности сессии.

## Сборка из исходников

Понадобятся Windows x64, Node.js 26 и npm 11.

```powershell
git clone https://github.com/yamixdev/vk-desktop.git
cd vk-desktop
npm ci
npm start
```

Создание installer:

```powershell
npm run build
```

Полезные команды:

| Команда | Назначение |
| --- | --- |
| `npm run check` | Линтер, быстрые unit-тесты и проверка VK Next |
| `npm run build:dir` | Unpacked Windows x64 сборка |
| `npm run build` | NSIS installer без публикации |
| `npm run publish` | Сборка и публикация релиза; подпись необязательна |

## Безопасность

- Удалённый контент работает без Node.js integration.
- Renderer запускается в sandbox с context isolation.
- IPC принимает только ограниченные схемами сообщения от главного frame VK.
- Внешние URL открываются системным браузером, а VK redirector не загружается в
  клиент.
- Локальные служебные страницы доступны только через закрытый allowlist
  `vk-desktop://local`.
- Production-сборка проверяет ASAR integrity и отключает опасные Electron fuses.
